# 扬琴 AI 助教 · 从调研到可运行原型

> 一位扬琴老师，把自己课上真正缺的那件东西做出来了：
> **老师 3 分钟布置，孩子照着练，练完自动回到老师眼前。**
>
> 这里放着完整链路：市场机会调研 → 产品定位收敛 → PRD → 研发规范 → **能立刻试用的双端原型**。

---

## 一、这个项目是什么

不是「AI 陪练」，也不是「自动纠错」。

这个产品的判断是：**乐器教学真正断掉的地方，不在课堂上，而在课堂之外。**

```
课堂（信息产生） → 课后（指令传递） → 家庭（执行） → 回课（验证）
                        ↑                                  ↑
              老师说的话，孩子回家忘一半          练没练、练得稳不稳，老师全靠猜
```

**根因只有一句话：老师的大脑是这条链上唯一的数据库。**

所以它做的事情是——把老师脑子里的东西，外化成「家长能执行、孩子能对照、老师能验证」的练琴任务卡，并且自动回收执行证据。

**这是一套「教学记忆的外化系统」。**

## 二、三条不可动摇的产品红线

这三条不是偏好，是写代码时会被打回的红线：

| # | 红线 | 为什么 |
|---|---|---|
| 1 | **AI 只做事实判断，不做价值判断** | AI 可以答「有没有练 / 练没练完 / 节奏稳不稳」，**绝不能**答「弹得对不对 / 好不好 / 认不认真」。后者一旦出现，就变成用算法给孩子下评语，老师和家长都会失去信任。 |
| 2 | **不排名、不打百分、不评星级** | 禁止排行榜、禁止积分商城、禁止「优秀/良好/及格」。动机要内生的，物质奖励和排名会触发过度理由效应（Deci 1971），把「我想弹」换成「我要拿分」。 |
| 3 | **不做实时打断式陪练** | 练琴被打断就会停止。产品只记录与反馈，不在练习过程中跳出来纠错。 |

还有一个关键参数：**练习难度按「85% 规则」自适应**（Wilson 2019, *Nature Communications* 10:4646 —— 最优错误率 15.87%）。太简单无聊，太难挫败，留 15% 出错空间学得最快。

## 三、为什么是这个方向（关键数据）

这些数字决定了产品形态，也决定了很多时髦路线**不能**走：

| 判断 | 数据 | 结论 |
|---|---|---|
| 市场在收缩，不是增长 | 音乐教育培训产值 2024 年 1554.8 亿（−3.8%）、2025 年 1469.2 亿（−5.5%） | 任何「高速增长」的 BP 起点都是错的 |
| 真人 1v1 陪练已被证伪 | 师资成本 >60% + 获客 ≈50% → 结构性亏损 >30%；快陪练 / 柚子练琴 / VIP陪练 / 小音咖全灭 | 重资产陪练不做 |
| 硬件 + 重度 AI 纠错也已被证伪 | 音乐笔记（智能腕带 + 8 维度 + 自称纠错 >99.5%）2017 年 A 轮后再无融资 | 不做硬件 |
| 扬琴第一痛点是**调音**不是陪练 | 与钢琴相反，扬琴每节课前要调律 | 入口设在调音，不在纠错 |
| 儿童池子在不可逆塌缩 | 2025 出生人口 792 万（−17%，较 2016 峰值 −55.7%）；北大 CIEFR：义务教育适龄儿童 2025–2035 降 50–60% | 不能只押儿童 |
| 银发端是增量 | 老年大学学员 2000 万（音乐类约 400–800 万）；有需求中老年约 2.5 亿，仅覆盖 8% | 第二曲线，但要靠渠道不靠投放 |

**目标用户**：教民乐的老师（渠道 + 信任入口）→ 学生家庭（付费方）。
**北极星指标**：周有效回课次数 / 学生（WER ≥ 2.5），不是 DAU。

## 六、怎么用（完整链路）

### 老师端（`/t`）

1. **学生档案** → 添加学生，**务必填手机号**（孩子用它登录）
2. **上课** → 选学生 → 选曲目 → **在五线谱上点音符加批注**（轮音 / 反竹 / 支手轮音 / 滑弹 / 花音…）→ 写微目标 → 可选：课堂录音、上传示范视频 → 保存并布置
3. **回课驾驶舱** → 一张表看全班：谁交了、练了几遍、几分几秒、稳不稳
4. **逐条批改** → 听录音 → 标「达标 / 需再练」，写具体的一句话反馈

### 孩子端（`/s`）

1. 输入手机号登录
2. 看到老师布置的任务卡：**曲目 + 老师的批注（谱面上高亮）+ 微目标 + 示范视频**
3. 点「开始练习」→ 计时 / 节拍器 / 记遍数 / 录音
4. 提交 → 老师那边**最多 3 秒**就看到

**联动机制**：老师端布置 → 孩子端立刻出现；孩子端提交 → 老师端立刻出现。两端共用一个后端，3 秒轮询 + 写操作即时推送。

## 七、技术栈与工程约定

- **零依赖**：原生 HTML/CSS/JS + Node 内置模块，没有 npm 包、没有数据库、没有构建步骤
- **五线谱**：自绘 SVG（不是图片，不是第三方库），音符可逐个点击批注
- **存储**：服务端 JSON 文件（可丢，原型阶段够用）；客户端 3 秒轮询 `GET /api/state`
- **降级**：云端只读文件系统时自动切纯内存；`file://` 打开时自动切单机模式

### 一条铁律

**`prototype/server/public/index.html` 是唯一源文件。**
`teacher.html` 和 `student.html` 由拆分脚本从它派生，**不要直接改派生文件**，否则下次拆分会被覆盖。
