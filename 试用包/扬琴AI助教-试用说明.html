老师端 · 四步走一遍

1. 学生档案 — 添加学生，填姓名 + 程度 + 登录手机号
2. 上课 — 选学生 → 选曲目 → 在五线谱上点音符加批注（轮音 / 反竹 / 支手轮音 / 滑弹 / 花音…）→ 写微目标（如「慢速 60，连奏 3 遍不错音」）→ 可录一段课堂示范、上传示范视频 → 保存并布置
3. 回课驾驶舱 — 一张表看全班：谁交了、练了几遍、练了多久、节奏稳不稳
4. 逐条批改 — 听录音 → 标「达标 / 需再练」→ 写一句具体的反馈（比如「第 2 小节轮音不均匀，先单手各 5 遍」）

孩子端 · 三步走一遍

1. 登录 — 输入老师给的手机号
2. 看任务卡 — 曲目 + 老师在谱子上画的重点 + 微目标 + 老师的示范视频
3. 练习并提交 — 计时 / 节拍器 / 记遍数 / 录音 → 提交，老师那边最多 3 秒就收到

三条设计红线（看到违反请立刻告诉我）

  • AI 只说事实，不说好坏：只回答「练没练、练了几遍、稳不稳」，绝不说「弹得对不对、好不好、认不认真」。
  • 不排名、不打分、不评星级：没有排行榜，没有积分商城，没有「优秀 / 良好 / 及格」。
  • 练琴过程中不打断：只记录与反馈，不在孩子弹的时候跳出来纠错。
这不是偷懒省功能，是刻意不做。孩子练琴的动机一旦变成「拿分、排名」，练琴本身就废了（过度理由效应）。

请帮我回答这 5 个问题（最重要的一步）

  1. 布置一次作业，从打开到发完，花了你几分钟？比你现在用微信发语音/打字快还是慢？
  2. 谱面批注这个功能，你会真的在课上用吗？还是下课后补？为什么？
  3. 回课驾驶舱这一屏，你看第一眼想知道的是什么？现在这屏上有吗？
  4. 如果一个家长说「我不想让孩子对着手机练」，你会怎么回？
  5. 如果这东西收费，你愿意付多少？（ ¥398 / ¥698 / ¥998 一年，或者「不愿意，除非…」）
