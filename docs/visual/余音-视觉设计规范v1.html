01设计哲学

「余音」这个名字定下的不是颜色，是气质：声音停下来之后还留着的东西。视觉上对应四个词——

关键词在界面里意味着什么
纸底色不是冷灰白，是宣纸暖白 #FAF8F4。谱面区微微泛黄（像旧谱纸），卡片是干净的白，靠材质差而不是边框区分层次
墨文字不用纯黑 #000，用墨色 #1C1A17；辅助文字是淡墨 #6B655C。五线谱谱线、音符符头同属墨色体系，谱面就是"写"在纸上的
朱砂全产品只允许一种强调色：朱砂 #B04A3A。它只出现在两种地方——老师落笔的批注、需要家长/学生行动的按钮。朱砂出现 = "这里值得注意"
渐弱声音是渐弱的，界面层次也是：黛青（主品牌）→ 竹青（孩子端）→ 淡墨（辅助）。不做高饱和撞色，不做渐变背景
一句话原则：这个产品的主角是"谱面 + 老师的批注 + 孩子的练习记录"，界面只需要安静地托住它们。凡是让界面比内容更响的设计（彩色大按钮、满屏徽章、进度条），都是错的。

02现状诊断：为什么显得 low

对照 public/index.html（2281 行，CSS 在 L7–176）。问题不在布局骨架（骨架其实是对的），在没有一套被严格执行的设计系统。

#问题证据（代码位置）观感后果

P8主色橙棕是"后台感"来源--brand:#c2410c（L11）+ 大面积实心橙按钮（截图 01 中整条橙色 CTA）像琴行教务 SaaS（小禾帮/小麦助教正是这类配色）
P9运维面板式状态徽章顶栏"●已同步 10:49"红绿点（L234–238）技术细节暴露给家长和老师
P10谱面批注像报错批注 badge：#c2410c 圆点 + 9px 白字浮在音符角上（L123），配 6 色马卡龙底谱面像被贴满荧光贴和错误标记，喧宾夺主
根因：MVP 阶段所有颜色/圆角都是"写到哪里算哪里"，没有 token 纪律。好消息是——全部问题都收敛在 :root 变量层和十几个组件类里，换一套 token 就能解决 60% 的观感问题。

3.3 新旧对照：砍掉了什么

旧（现状）

  • brand #c2410c 橙棕 + 紫色 #7c3aed 并存，两个"主色"打架
  • 批注 6 种马卡龙：红/橙/蓝/紫/绿/粉底色 + 高饱和描边
  • bad #dc2626 正红，被用在"新作业"小红点上——正红在中文语境里是喜庆色，用在提醒上过重

新（余音）

  • 老师端黛青、孩子端竹青，一个页面只出现一个品牌色
  • 批注只有朱砂一种颜色，技法类型用文字标签区分（见 §06）
  • "新作业"红点改用朱砂 #B04A3A——既醒目又不刺眼
对比度自检：墨 #1C1A17 于宣纸 #FAF8F4 = 对比度约 15.9:1（WCAG AAA）；淡墨 #6B655C 于宣纸 ≈ 5.5:1（AA）；朱砂 #B04A3A 白字 ≈ 5.2:1（AA）。全部达标。

04字体系统

两套字体、各司其职：宋体只做"门面"（品牌字/页面大标题），正文全部黑体保可读性。绝不让宋体进表单和小字。

层级字体栈字号 / 字重用在哪
品牌字 Display"Songti SC","STSong","Source Han Serif SC","Noto Serif SC",SimSun,serif22–40px / 500Logo「余音」、页面 H1、空状态大字、引导页
标题 HeadingPingFang SC（系统栈）17px / 600卡片标题、弹层标题
正文 BodyPingFang SC（系统栈）14.5–15px / 400，行高 1.7一切正文

为什么宋体只做门面：宋体在小字号和浅色底上笔画易糊，正文用它牺牲可读性；但 22px 以上的宋体标题自带"谱纸/书页"的人文气，是花 0 成本就能拿到的品牌差异化（竞品全线黑体）。Windows 回退 SimSun 需配 font-weight:500–600 避免发虚。

token值层级语义
--sh10 1px 2px rgba(28,26,23,.04)静态卡片（默认，极轻）

5.3 间距：4 的倍数

4 / 8 / 12 / 16 / 20 / 24 / 32 / 48。卡片内边距统一 16px（原 13–14px），卡片间距 12px，区块间距 24px。页面左右安全边距 16px（手机）/ 24px（桌面）。

06批注系统重构（本次升级的核心）

谱面批注是产品灵魂（「在五线谱上点音符加批注」是 README 的主打功能），也是现在观感最差的部分。重构为"一种颜色 + 三种笔触 + 文字标签"：

笔触样式语义
朱砂实线朱砂 1.5px 实线描边 + #F7E8E3 极浅底老师落笔的重点：重点 / 难点 / 轮音先慢——"这里要注意"
黛青点线黛青 1.5px 点状描边 + 无底方法提示：慢练 / 分段 / 变速——"这里要这么练"
墨色虚线墨 1px 虚线 + 无底结构标记：分句 / 乐段 / 竹法标记——"这里是这样划分的"

旧：6 色马卡龙 + 红点角标

5 6 1 2 3 5

① 6 色暗示 6 个等级，家长会问"紫色是不是比蓝色严重"；② 与红线二（不做价值判断）隐性冲突——颜色多寡天然构成"严重度排序"；③ 彩底盖住谱线，谱面花。

新：朱砂一种颜色，笔触分语义

5轮音·先慢 6慢练×4 3分句

① 单色 = 老师只是"落笔提醒"，没有好坏排序，与红线完全对齐；② 描边不遮谱线（底色透明或极浅）；③ 类型写在上方小标签里，9–10px 朱砂/墨色小字，孩子一眼看到"这里为什么被圈"。

落到孩子端的一句话体验：旧版孩子看到彩虹底色，问"这些颜色什么意思"；新版孩子看到朱砂圈，直接明白"老师让我注意这几个音"。认知负担从"理解一套颜色系统"降为"找到唯一的红色"。

07Logo 与品牌符号

品牌符号只有母题：击弦——琴竹落下，朱砂音点在琴弦上亮起，声一圈圈散开。整个符号只用三种元素：一道弦、一点朱砂、一支琴竹，零滤镜、零纹理，干净得可以印在名片上。三个候选方向：

候选 L1 · 朱砂击弦（定稿推荐）
余音

一道弧线琴弦 + 两圈涟漪环 + 径向渐变朱砂音点 + 填充纺锤形琴竹。一眼读出"击弦发声"：点在弦上，声在扩散。零滤镜全干净，48px / 24px 小尺寸实测清晰，是三者中唯一自带"琴"的叙事的。

候选 L2 · 纯音点涟漪
余音

只有音点+涟漪，最抽象耐看，做 favicon、页脚水印、空状态装饰；24px 下仍是一个清晰的朱砂点。缺"琴"的叙事，需字标补位。

候选 L3 · 纯字标

最克制：宋体「余音」+ 一道朱砂底线。极端耐看、不依赖图形；弱在缺可独立使用的图形符号。做顶栏与打印物料（任务卡页脚）。

定稿组合：L1 朱砂击弦做 App 图标 / 启动页 / 登录页主视觉；L2 纯音点涟漪做 favicon、水印与空状态装饰；L3 纯字标做顶栏与打印物料。三者共用朱砂主色与宋体，视觉同源。工艺说明：全部为零滤镜的干净矢量——音点用径向渐变模拟朱砂釉面（亮部 #C4573F → 暗部 #8E3025），琴竹用填充纺锤形路径（非描边线，有粗细起收），涟漪环是两圈细描边（透明度 0.35 / 0.18）。暗底版：朱砂整体提亮一档（#D9704F→#A63A2C），弦与琴竹换米白 #EDE6D8，已实测成立。顶栏替换方案：删掉现在的 .dot 圆点和 ⚙ emoji，改为「L2 音点标 + 宋体余音」+ 同步状态降级为顶栏右上一枚 4px 灰点（只有异常时才变朱砂——正常状态不打扰）。

09动效

动效只有一个母题，还是击弦。凡是"完成一个动作"，朱砂音点亮起、一圈涟漪向外扩散又归于平静；其余过渡 120–180ms 淡入淡出，不做弹跳、不做进度火苗。

完成微目标 / 点按批注音符的涟漪反馈（自动循环演示）

完成微目标 / 点按批注音符：朱砂音点亮起，涟漪自音点向外扩散又消隐（2.6s 一轮）。动画仅 transform+opacity，且尊重 prefers-reduced-motion。

10红线自检

产品三条红线逐条对照新视觉——视觉本身就是红线的执行层。

红线新视觉如何执行状态
① AI 只做事实判断，不做价值判断批注单色化（朱砂），废除 6 色严重度暗示；驾驶舱不出现红色分数/星级；回课只显示"练了几遍/几分钟"事实通过
② 不排名、不竞技无排行榜组件、无火焰/徽章/连胜；"本周回课率"只给老师本人看趋势，不跨学生比较通过
③ 练琴中不打断无弹窗型激励；涟漪反馈 400ms 一次性收敛；计时/节拍器区无闪烁动画通过
④（隐含）家长退出机制友好任务卡信息层级把"目标与截止"讲清楚，无倒计时压迫感设计（截止时间只是灰色小字）通过
